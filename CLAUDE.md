# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

"gomachine" is a Go code generator. It reads a MySQL schema (`information_schema`) plus a `model.json` and generates, per table:
Go (fiber REST: models, controllers, routers, enum constants), Kotlin/Spring Boot (JPA entity, repository, service, controller),
Dart/Flutter models, React / Vue 3 TypeScript clients, and a Rust backend (axum 0.8 + sqlx 0.9) mirroring the Go one. Templates use CloudyKit Jet. README.md (Korean) is the detailed spec of
the generated behavior; keep it in sync when behavior changes.

## Key Commands

- `make install` - builds `bin/model`, installs it to `~/bin/buildtool-model`, copies `views/*` to `~/bin/buildtool/` and `bootstrap/` to `~/bin/buildtool/bootstrap/`
- `make run` - runs the generator from source (`go run .`)
- `make model` - builds `bin/model`
- `make test` - `go test -v ./...`
- `make clean` - removes local `bin/` and what `make install` put in `~/bin`
- Before finishing a change: `gofmt -l .`, `go vet ./...`, `go test ./...`

### Running the Tool

```bash
buildtool-model <projectDir> [languages] [package_name] [--force]
```
- If `<projectDir>/model.json` exists it is used, and relative `*ModelFilePath` values are resolved against `<projectDir>` (empty `goModelFilePath` = `<projectDir>`; `config.ResolvePaths`). Otherwise (no arg, `.`, or no model.json there) the legacy mode reads `./config/model.json` from the **current directory** (with `modelJsonPath` → that directory's `model.json`), paths relative to cwd.
- `languages`: overrides model.json's selection. One or comma-separated: `go`, `kotlin`/`spring`, `dart`/`flutter`, `react`, `vue`, `rust`, or `all`
- `package_name`: Go import path prefix of the target project; defaults to the `module` line of `{goModelFilePath}/go.mod` (`config.GoModule`), then model.json `database` with a warning
- `--force`: overwrite existing files that lack the generated header (`util.Force`)
- Templates are loaded at runtime from `$HOME/bin/buildtool/{go,kotlin,dart,react,vue,rust}` (so tests/harnesses point `HOME` at a dir whose `bin/buildtool` links to `views/`)
- If that `model.json` has `modelJsonPath` it is a **pointer**: `config.FollowPointer` loads the target dir's model.json (path relative to the pointer), resolves output paths against the target, and the pointer's `languages` (if any) replace the target's.
- `reactTsOutDir` / `vueTsOutDir` / `reactTsSemicolons` / `vueTsSemicolons` override `tsOutDir` / `tsSemicolons` per language (`GetTsOutDir` / `UseTsSemicolons` check `cnf.Language`).

### New project workspace (`init`)

```bash
buildtool-model init <name> [--go --spring --rust --react --vue] [--dir P] [--template-source github|DIR] [--branch B] [--db-port N] [--package PKG] [--no-git] [--db-up] [--gen] [--force]
```
- `initcmd.go` (dispatched first in `main()`), tests `initcmd_test.go` (fixture templates). Default languages go+react; at least one backend required; name `[a-z][a-z0-9_]*` ≤ 32.
- Creates `<name>/` with bootstrap assets (`~/bin/buildtool/bootstrap`, else the `go:embed` copy of `bootstrap/`), root `.env` / Makefile / README, authoritative root `model.json`,
  and sub-projects `<name>_go|_spring|_rust|_web|_vue` cloned (`git clone --depth 1 --branch B https://github.com/kobums/basicproject_*`) or copied from DIR, `.git` stripped.
- Per sub-project: own template identifier (go.mod module / rootProject.name / Cargo package / package.json name, plus repo name) replaced in all text files; frontends also bare `basicproject` in index.html + src/;
  `.env` from `.env.example` with shared DB creds + JWT_SECRET (backends) or VITE_PROXY_TARGET = first backend port (go 8007 > spring 8081 > rust 8008);
  model.json replaced by a pointer `{"modelJsonPath": "..", "languages": {<lang>: true}}`; `git init -b main` + first commit unless `--no-git`.
- Refuses non-empty target without `--force`, never overwrites existing sub-project dirs, removes only what it created on failure.

## Architecture

- `main.go` - loads config, lists tables, `util.ResolveTableNames` (name collisions), `util.CheckTableConfigs` / `util.FindTableConfig` (table config matching: exact name first, then `_`/case-insensitive), pre-validates `session` columns (auth=jwt + unusable session column → exit 1 before writing anything), then runs each enabled generator per table
- `config/` - `ModelConfig` / `Gpa` structs. `config.Load`/`Parse` are strict: JSON syntax/type errors are fatal (`Init` exits 1), unknown keys only produce warnings
- `util/generated.go` - generated-file header (`util.GeneratedHeader` = `// Code generated by gomachine. DO NOT EDIT.`, `util.RustGeneratedHeader`), `IsGeneratedFile` (first line; legacy TS `// Auto-generated ...` counts), `WriteGenerated` (skip + warn when the existing file lacks a header unless `Force`; write only when changed). Every regenerated output of every language goes through it; user-owned files use `WriteIfMissing`
- `bootstrap/` - standard project assets copied by a later `init`: `db/schema.sql` (MariaDB user_tb/board_tb), `docker-compose.yml` (mariadb:11.4), `.env.example`, sample `model.json` (`bootstrap_test.go` checks them)
- `util/` - shared rules every generator must use: type mapping (`GetType`), names (`ModelName`, `FileName`, `JSONKey`, `SearchSegment`, `RangeParams`, `DedupeColumns` incl. the reserved `extra` key), enum codes, `ParseFuncs` (custom methods), `ProtectedColumns`, `ResolveJoins` (join table + local column resolution, skipped joins warn), `SessionColumnError`, `KotlinTypeName` (Kotlin class names clashing with Kotlin/Spring/JPA types get `Entity`/`Enum` suffix), Rust names in `util/rust.go` (`RustIdent`, `RustField(s)`, `RustModelName`, `RustEnumType`, `RustModule`)
- `go/`, `kotlin/`, `dart/`, `react/`, `vue/`, `rust/` - one generator per language (`Process{Lang}`); Vue reuses `react.BuildTemplateData`
- `views/go/` (model, rest, const, domain_router), `views/kotlin/` (entity, repository, service, controller, enums), `views/dart/` (model), `views/react/` (contract, model, type), `views/vue/` (contract, model, type, composable), `views/rust/` (model, handler, models_mod, handlers_mod, routes, main, `support/*` runtime modules)

### Generated Code Structure

- **Go** (under `goModelFilePath`): `models/{name}.go`, `models/{name}/{name}.go` (enum constants), `controllers/rest/{name}.go`, `router/routers/{name}.go`; after all tables `gocodegen.Finish` writes `router/routers/generated_routes.go` (`SetupGeneratedRoutes(group fiber.Router)` calling the Setup{Model}Routes written this run, sorted). Generated controllers need `controllers.Controller{Session *Session}` with `Session{Id int64; Email string; Level int}` (README "Go Session 계약")
- **Kotlin/Spring** (`springBoot` 3|4, default 4: Jackson 3 `tools.jackson`, Spring Data 4 `Specification`, `encode(...)!!`; 3 = legacy output) (under `kotlinModelFilePath`, which must be the directory of `kotlinPackage`, default package `com.gowoobro.gymspring`): `entity/`, `repository/`, `service/`, `controller/`, `enums/{name}/Enums.kt`, `support/DateParams.kt` (always regenerated), `config/SessionProvider.kt` (auth=jwt, created once, never overwritten)
- **Rust** (under `rustModelFilePath` = crate root, files go in `src/`; modules use `crate::` paths): `rustcodegen.Prepare` (once per run, before tables) renders `views/rust/support/*.jet` to `src/support/*.rs` (regenerated, written only when content changed via `util.WriteIfChanged`; `support/auth.rs` JWT→Session is user-owned, `util.WriteIfMissing`), `src/main.rs` if neither main.rs nor lib.rs exists (user-owned), and warns about missing Cargo.toml deps; `rustcodegen.Finish` (after all tables) rewrites `src/models/mod.rs`, `src/handlers/mod.rs`, `src/routes.rs` and deletes stale `src/models/*.rs` / `src/handlers/*.rs` whose first line is `rustcodegen.GeneratedHeader` (`// @generated by gomachine - do not edit`, carried by every regenerated file) but that were not produced in this run; a table whose module name was already generated in the run is skipped with a warning. `ProcessRust` (per table, `rust/table.go` builds the data with the same rules as `go/main.go`) renders `views/rust/model.jet` → `src/models/{module}.rs` and `views/rust/handler.jet` (handler bodies built in `rust/handler.go`) → `src/handlers/{module}.rs` with the Go router's routes/params/auth rules; routes with the same shape are deduped (axum panics on conflicts). The support files carry `#[cfg(test)]` Rust tests. Pools must be built with `support::state::connect`/`connect_lazy` (sqlx `timezone(None)`, so TIMESTAMP reads match Go)
- **Dart** (under `dartModelFilePath`): `{table}.dart`
- **React / Vue** (under `reactModelFilePath` / `vueModelFilePath` + `tsOutDir`, default `src`): `models/{name}.ts`, `models/contract.ts`, `types/{name}.ts`, React `hooks/use{Model}.ts`, Vue `composables/use{Model}.ts`, and `services/api.ts` only if missing (user-owned fetch adapter). `tsSemicolons: false` strips statement semicolons
- Non-Go languages without an output path are skipped with a warning

### Configuration (`model.json`)

- DB connection (`server`, `database`, `user`, `password`; env `DB_HOST`/`DB_USER`/`DB_PASSWORD` override)
- `languages` map (`{"go": true, "spring": true}`, `"all": true`), falling back to legacy `language`, then `go`
- `auth` (`"jwt"` → login required everywhere except User create), `adminLevel`, `timezone` (createddate / Spring date conversion; empty = Asia/Seoul)
- `springBoot` (3|4, default 4), `tsSemicolons` (default true), `tsOutDir` (default `"src"`)
- Unified JWT (Go/Spring/Rust templates, Rust default `auth.rs`): HS256, `JWT_SECRET`, claims `{sub: "<id>", id, email, level?, iat, exp}` (seconds)
- `kotlinPackage`, output paths (`goModelFilePath`, `kotlinModelFilePath`, `dartModelFilePath`, `reactModelFilePath`, `vueModelFilePath`, `rustModelFilePath`), `modelJsonPath`
- `table[]`: `name`, `map` (enums), `method` (Go custom methods), `join`, `compare`, `session`, `search`, `primary`, `protect`

### Type Mapping

`util.GetType` maps MySQL `data_type` per language (`GetTypeUnsigned` also takes `column_type`'s `unsigned`, used by Rust only). Unknown types log a warning and fall back to string.

| MySQL | Go | Kotlin | Dart | TypeScript | Rust |
|---|---|---|---|---|---|
| `int`, `integer`, `smallint`, `mediumint`, `year` | `int` | `Int` | `int` | `number` | `i32` (`u32` if unsigned) |
| `bigint` | `int64` | `Long` | `int` | `number` | `i64` (`u64` if unsigned) |
| `tinyint`, `bit` | `bool` | `Boolean` | `bool` | `boolean` | `bool` |
| `float`, `double`, `real` | `float64` | `Double` | `double` | `number` | `f64` |
| `decimal`, `numeric` | `float64` | `BigDecimal` | `double` | `number` | `f64` |
| `char`, `varchar`, `*text`, `enum`, `set`, `json` | `string` | `String` | `String` | `string` | `String` |
| `datetime`, `timestamp` | `string` | `LocalDateTime` | `String` | `string` | `String` |
| `date` | `string` | `LocalDate` | `String` | `string` | `String` |
| `time` | `string` | `String` | `String` | `string` | `String` |
| `binary`, `varbinary`, `*blob` | `[]byte` | `ByteArray` | `String` | `string` | `Vec<u8>` |

Go reads `bit` columns as `(col+0)`. Columns in `table[].map` become enum types (codes = position in `data`).

### Naming

- Tables: `_tb` / `_vw` stripped (`user_role_tb` → `UserRole`, files/URLs `userrole`). `_vw` is read-only. Name collisions: `_tb` keeps the name, others are renamed (`UserView`); config must use the full table name for renamed tables.
- Columns: prefix before the first `_` is dropped; API name = `util.JSONKey` (lowerCamel). Every generator must use `JSONKey` / `SearchSegment` / `RangeParams` / `DedupeColumns`; `json_keys_test.go` and `enum_codes_test.go` check the languages agree.
- List filters / `/search`: never on `id`, `primary` columns, password, binary columns (all backends and TS agree).
- Kotlin controllers name all locals/params with a leading `_` (column properties never contain `_`) and bind query params with explicit `@RequestParam("name")`.

### HTTP contract

React/Vue/Dart must work against both Go and Spring. README.md "HTTP 계약" documents routes, response shapes and errors. On the Go side only add routes/fields; register static routes before `/:id`.

## Testing

- `go test ./...` (unit tests in `util`, `config`, `go`, and cross-language tests in the root package that render templates into a temp dir with `HOME` pointing at `views/`)
- Generated code is verified out of tree: Go output with `go build`/`go vet` in a stub project, Kotlin output with `kotlinc` against Spring/JPA/Jackson/Hibernate jars, TS with `tsc --strict`
